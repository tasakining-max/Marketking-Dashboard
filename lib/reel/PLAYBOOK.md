# คู่มือตัด Reel สไตล์หนิง (สำหรับ ฟุต / คัต / แพ็ค)

ทุกข้อในไฟล์นี้มาจากคำสั่งและการแก้ของหนิงจริงๆ ห้ามตัดทิ้งหรือเปลี่ยนเองโดยไม่มีคำสั่ง ถ้าคำสั่งในงานขัดกับไฟล์นี้ ให้ทำตามคำสั่งในงานนั้น

## ที่เก็บไฟล์
- ฟุตเทจต้นฉบับ: ห้ามแก้ ห้ามย้าย ห้ามลบ
- ผลสแกน: `~/Movies/FilmCraft/<ชื่อโฟลเดอร์งาน>/_scan/` (footage.txt, <คลิป>.json, <คลิป>.jpg)
- โปรเจกต์ต่อ Reel: `~/Movies/FilmCraft/<ชื่อโฟลเดอร์งาน>/<ชื่อ Reel>/<ชื่อ Reel>.fcproj`, กราฟิกใน `gfx/`, ไฟล์หน้าเนียนใน `media/`
- ส่งออก: `<ชื่อ Reel>.mp4` ทับไฟล์เดิมทุกรอบ (ร่างระหว่างทาง `- ร่าง.mp4`) ปก `<ชื่อ Reel> - ปก.jpg/.png`
- FilmCraft ต้องเปิดอยู่ในโหมด bridge (`--control 7802`) — สคริปต์ทั้งหมดคุมแอปตัวจริง ถ้าต่อไม่ได้ให้แจ้งหนิง ห้ามเปิดแอปซ้อน

## เครื่องมือ (lib/reel/)
| สคริปต์ | ใช้ทำอะไร |
|---|---|
| `scan.py <โฟลเดอร์>` (รันผ่าน `uv run -q --with mlx-whisper --with opencv-python python`) | ถอดเสียงทุกคลิป + ภาพเรียงเฟรม + เดาการหมุนภาพ |
| `cutlist.py pick.json` | เลือกช่วงประโยค → ตัดช่องว่าง ≥0.10 วิ อัตโนมัติ (เว้นอากาศ 1 เฟรม) + ทิ้งช่วง drop → cut.json |
| `check.sh <ไฟล์ส่งออก>` | ถอดเสียงไฟล์ส่งออกครั้งเดียว (Whisper ทางเดียวที่อนุญาต) |
| `build.py cut.json` | สร้างโปรเจกต์ + วางช่วงคลิปบน V1/A1 + หมุนภาพ + ลดเสียงรบกวน + ปรับแสงให้เท่ากัน + ส่งออกร่าง |
| `gfx.py gfx.json` | ทำกราฟิกคำ (PNG โปร่งใส 1080x1920) ตามชนิดคำ |
| `place.py place.json` | วางกราฟิก + SFX + เพลง + รูปท้ายคลิป บนซีเควนซ์ที่เปิดอยู่ |
| `smooth.py <ต้นฉบับ> <ผล> [rot]` | หน้าเนียน (หาหน้าทุกเฟรม แล้ว bilateral เฉพาะหน้า) |
| `cover.py cover.json` | ทำปก |
| `card.py card.json` | ใส่คลิป ปก แคปชั่น Todo ลงการ์ด |
| `fc.py` | `ex(command, params)`, `inspect()`, `export()`, `envelope()`, `luma()`, `loudness()` |
`filmcraft-cli --bridge 127.0.0.1:7802 commands <คำ>` ใช้ค้นคำสั่ง, `describe <id>` ดูพารามิเตอร์

## 1. เลือกเรื่อง (ฟุต)
- Reel 1 ตัว = 1 เรื่อง 1 ประเด็น ยาว 15–40 วิ เรียงตามลำดับที่พูดจริง **ห้ามสลับฉากเอาท่อนเด็ดมาไว้หน้า (cold open)**
- อย่าเสนอเรื่องที่ทำไปแล้ว (เช็คการ์ดในบอร์ดที่ชื่อคล้ายกัน)
- ช่วงที่มีปัญหาสินค้า (รั่ว ซึม เสีย) ห้ามเสนอ หรือเสนอแบบ "เข้าไปดูแลเชิงรุก" พร้อมเตือนหนิง
- มีเด็ก/นักเรียนในภาพ → เตือนให้ขอความยินยอมโรงเรียน/ผู้ปกครองก่อนโพสต์
- Whisper ภาษาไทยเพี้ยนบ่อย คำสำคัญ (ชื่อคน ชื่อสถานที่ ตัวเลข สโลแกน) ให้ถอดซ้ำแบบใส่ initial_prompt แล้วบอกหนิงว่าคำไหนยังไม่แน่ใจ ชื่อทางการ (โรงเรียน หน่วยงาน) ต้องเช็คกับเว็บจริง
- ช่วงที่มีคำหยาบ ให้ข้ามหรือบี๊บ

## 2. ตัดเสียงพูด (คัต) — ทำครบตั้งแต่รอบแรก ไม่ต้องรอสั่ง
1. ต่อคำชิดกัน เหลือเงียบหัว/ท้ายแต่ละท่อน 0–2 เฟรมเท่านั้น
2. ตัดทุกช่องว่างระหว่างคำ แม้ 0.1–0.2 วิ
3. ตัดตามความหมาย: ทิ้งทั้งวลีที่ซ้ำ ลังเล พูดผิดแล้วพูดใหม่ เออ อืม เอ่อ เสียงหายใจ คำพูดแทรกของคนถามที่ไม่จำเป็น
4. คำซ้ำ/ติดอ่าง ตัดตัวแรกออก (ดูจาก envelope ว่าเป็นพยางค์ซ้ำจริง Whisper มักกลืนคำซ้ำ)
5. คำ "ก็…" คิดก่อนตอบที่เป็นธรรมชาติเก็บได้ แต่ลากเสียงกลางประโยคตัด (เหลือสระยาว ≥0.25 วิ ไม่งั้นเสียงเพี้ยน)
6. คำสุดท้ายของประโยคต้องครบเสียงวรรณยุกต์ ห้ามตัดหาง
7. **ห้ามถอดเสียงซ้ำ** — scan.py ถอดไว้แล้วพร้อม word timestamps ใน `_scan/<คลิป>.json` (segments[].words[]) ใช้ไฟล์นั้นตรงๆ หาขอบคำจาก word timestamps + `envelope()` (dB ทุก 50 ms) ตัดที่จุดเสียงตก ถ้าคำสำคัญถอดไม่ชัด ให้จดไว้ใน unsure ให้หนิงฟัง ไม่ต้องถอดซ้ำ
8. ตัดเสร็จ ถอดเสียงไฟล์ร่างที่ส่งออก **ครั้งเดียวทั้งไฟล์** เช็คว่าคำไม่ขาด ไม่มีคำซ้ำค้าง (โหลด Whisper ครั้งละ ~1 นาที ห้ามถอดทีละท่อน)
9. ถ้ามีหลายเทค ใช้เทคที่ชัดที่สุด หรือถ้าหนิงสั่ง "ใส่ทุกเทค" ให้เรียงคำตอบทุกเทคต่อกัน
10. ภาพ b-roll ที่ไม่มีคนพูด **ปิดเสียง** (`"mute": true`)

## 3. ภาพ
- คลิป Canon ถ่ายตะแคง (1920x1080) → หมุน 90/-90 สเกล 100.4 (scan.py เดาให้ เช็คจากภาพเรียงเฟรมอีกที)
- แสง: ปรับแค่ Exposure ให้ทุกซีนสว่างใกล้กัน (~120–130) ห้ามแต่งสี คอนทราสต์ ความอิ่ม ชาร์ป ถ้าคิดว่าต้องเกรดให้ทำภาพก่อน/หลังถามก่อน
- ซูม: ซูมสลับ 100/110/112/108% ตรงรอยตัดเนื้อหา ยึดที่ปลายเท้า ห้ามตัดเท้า ถ้าจัดคนกลางไม่ได้โดยไม่ตัดเท้าไม่ต้องซูม
- ไม่ใส่ freeze frame ไม่ใส่ทรานซิชันยาว (ถ้ามี 6–8 เฟรม)
- หน้าเนียน: เฉพาะเมื่อสั่ง ใช้ `smooth.py` แล้ว relink ทำภาพก่อน/หลังให้ดูก่อน

## 4. เสียง
- Essential Sound: Dialogue + Reduce Noise + Reduce Rumble ทุกคลิปพูด (build.py ทำให้) กลางแจ้งห้ามลดแรง (เสียงหลอน)
- Mix: hard limiter −1.5 dB เป้า ≈ −14 LUFS, peak ≤ −1.5 dB (`loudness()` เช็คจากไฟล์ส่งออก)
- เพลง: ใส่เพลงที่ใช้เชิงพาณิชย์ได้ เบาใต้เสียงพูด (≈ −20 dB) ดังขึ้นช่วงไม่มีคนพูด (≈ −5 dB) เฟดเข้า/ออก — ตัวเลือกใน `~/Movies/FilmCraft/MD Service/ทดลองเพลง/` (Vlog Vibes ใช้ล่าสุด) บอกหนิงให้เช็คสิทธิ์เพลงก่อนโพสต์

## 5. INF (กราฟิกคำ) — `gfx.py`
- น้อยแต่โดน: เฉพาะคำสำคัญ 2–4 พยางค์ (ชื่อสถานที่ ตัวเลข คำเคลม) ไม่ใช่ซับทั้งประโยค ไม่มีหัวข้อใหญ่ตอนเปิดคลิป
- **ต้องสื่อความหมายตามที่พูด** เช่นพูด "ไม่ใช่แค่วัด โรงเรียนก็มา" → "ไม่ใช่แค่วัด" + ✓ "โรงเรียนก็มา!" (ไม่ใช่ ✓วัด ✓โรงเรียน)
- ชนิดคำ = หน้าตาต่างกัน ห้ามใช้แบบเดียวทั้งคลิป: check (รายการ), claim (คำเคลมบนใบพัดทาซากิ), place (หมุด + ชื่อสถานที่ ยาวให้แบ่ง 2 บรรทัด ชื่อทางการเขียนเต็ม), province (จังหวัดในกรอบมุม), number (ตัวเลขเงิน + หน่วยฟ้า), cool (เกล็ดหิมะ + คำฟ้า), quote
- ตำแหน่ง: อยู่ใน safe zone x 54–880, y 384–1440 ห่างหัวคน ≥ 60 px ห้ามทับหน้า ไอคอนห้ามบังตัวหนังสือ ตัวหนังสือห้ามล้นขอบรูปทรง — ซ้อนกราฟิกบนเฟรมจริงแล้วเปิดดูทุกชิ้นก่อนวาง
- เข้า: คำ = slam (140→95→100% ใน 4 เฟรม), ภาพ = soft rise ค้าง ≤ 2.5 วิ เว้นว่าง ≥ 0.5 วิ ก่อนชิ้นถัดไป (ยกเว้นประโยคเดียวกันต่อกันได้) คลุมรวม ~50–60% ของคลิป
- มีแอร์จริงในภาพ → ห้ามแปะรูปแอร์ ให้กราฟิกเล่นกับแอร์จริง (ลมเย็น/เกล็ดหิมะไหลจากขอบล่างของแอร์, วัดตำแหน่งแอร์ต่อช็อต, สลับ 3 เฟส ทุก 4 เฟรม = `cycle`)

## 6. SFX (`~/Movies/FilmCraft/_SFX Library/` ดู README.txt)
- 1 เสียงต่อ 1 กราฟิก ตรงเฟรมแรกที่กราฟิกเด้ง ไม่ใส่ตามซับ
- 2 ตระกูล: ป๊อป (poco / popmouth สลับกัน −8/−9 dB) กับคำ, วืด (stickswing −12 dB) กับภาพ, shine สั้นเบา −14 dB ปิดท้ายได้
- เสียงเดิมห้ามติดกันเกิน 3 ครั้ง (พยายามไม่ซ้ำติดกันเลย)
- รูปท้ายคลิป (เมื่อมีรูปให้): การ์ดรูปเอียงขอบขาวบนพื้นเบลอ 1 รูป = 1 แชะชัตเตอร์ ห่างกัน ~13 เฟรม รูปสุดท้ายค้าง ~1.4 วิ (`place.py` photos)

## 7. ปก (`cover.py`)
- เฟรมจริงที่เห็นคน/สินค้าชัด หน้ายิ้ม ไม่มีกราฟิกทับ โลโก้ Tasaki บน + บรรทัดเล็กฟ้า + คำใหญ่ไล่ฟ้าขอบขาวเรืองแสง + บรรทัดรองขาว ตัวหนังสืออยู่เหนือ y≈600 ไม่บังหน้า/แอร์

## 8. แคปชั่น
- ภาษาพูด สั้น 4–8 บรรทัด ขึ้นต้นด้วยประโยคเด่นจากคลิป อีโมจิพอประมาณ ชื่อสถานที่/คนสะกดถูก (ทาซากิ, เฮียโก้) ปิดด้วยแฮชแท็ก 5–7 ตัว (#TasakiAir #ทาซากิ #แอร์ทาซากิ + เฉพาะเรื่อง)
- ห้ามแต่งข้อมูลที่ไม่มีในคลิป (ราคา สเปก จำนวน)

## 9. ส่งงานให้หนิง
- ตอบสั้น อ่านง่าย ภาษาไทย: ได้คลิปกี่วิ มีอะไรบ้าง ไฟล์อยู่ไหน และสิ่งที่ยังไม่แน่ใจ (คำที่ถอดไม่ชัด สิทธิ์เพลง ความยินยอม) ถามได้ไม่เกิน 1 คำถาม
- การ์ด: ใส่เมื่อหนิงสั่ง/อนุมัติเท่านั้น (`card.py`, ไม่สร้างการ์ดใหม่เองถ้าไม่สั่ง)
